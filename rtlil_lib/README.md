# RTLIL Standalone Library

This is an extracted standalone version of Yosys RTLIL (Register Transfer Level Intermediate Language) library.

## Structure

- `include/` - Header files from kernel/
- `src/` - Source files from kernel/
- `test/` - Test programs demonstrating RTLIL API usage

## Building

```bash
make
```

## Usage

See `test/simple_example.cc` for basic RTLIL API usage.
